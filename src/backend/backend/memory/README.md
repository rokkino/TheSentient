# AI Memory

This directory contains data storage for the AI features associated with each tab in the application.

## Structure

- `bot/`: Memory and data for the Bot tab.
- `chat/`: Memory and data for the Chat tab.
- `earnings/`: Memory and data for the Earnings tab.
- `flex/`: Memory and data for Flex tabs.
- `news/`: Memory and data for the News tab.
- `stocks/`: Memory and data for the Stocks tab.
- `strategy/`: Memory and data for the Strategy tab.

## Usage

The AI services should store and retrieve persistent data (e.g., context, history, preferences) from the corresponding subdirectory.
